# Tatlı Hesap Makinesi 🌸🧮

HTML, CSS ve JavaScript kullanılarak tasarlanmış, pembe ve krem tonlarında, el yapımı/çizim hissi veren şirin bir hesap makinesi web uygulaması.

## 🎀 Özellikler

- **Estetik Tasarım:** Pastel pembe ve krem renk paleti, eğik duruşu ve pofuduk butonlarıyla göze hitap eden sevimli bir arayüz.
- **Şirin Detaylar:** Butonların üzerinde `^.^`, `u.u`, `;;` gibi tatlı metin yüz ifadeleri (kaomoji).
- **Temel Matematik İşlemleri:** Toplama, çıkarma, çarpma, bölme ve yüzde hesaplama.
- **Ekstra Fonksiyonlar:** Silme (C) ve son karakteri silme (off) tuşları.
- **Tepkisel (Interactive) Butonlar:** Tıklandığında içeri göçme efekti veren (box-shadow animasyonu) buton tasarımı.

## 🛠️ Kullanılan Teknolojiler

- **HTML5:** Yapısal iskelet.
- **CSS3:** Flexbox ve Grid sistemleri ile buton yerleşimi, özel renk paleti (`:root` değişkenleri), gölgelendirmeler ve el yapımı görünümü veren düzensiz köşe yuvarlatmaları (`border-radius`).
- **JavaScript:** Hesaplama mantığı, ekran güncelleme ve silme fonksiyonları.

## 🚀 Nasıl Çalıştırılır?

Bu proje herhangi bir sunucu veya kurulum gerektirmez.

1. Kodları içeren dosyayı (`index.html` olarak kaydedebilirsiniz) bilgisayarınıza indirin.
2. Dosyaya çift tıklayarak favori web tarayıcınızda (Chrome, Safari, Edge vb.) açın.
3. Hesap makineniz anında kullanıma hazır!

## 📝 Geliştirme Notları

Proje tek bir HTML dosyası içerisinde (CSS `<style>`, JS `<script>` etiketleri ile) oluşturulmuştur. Hesaplama fonksiyonu, basit ve hızlı olması için `eval()` kullanılarak yazılmıştır [cite: 3].
